序章

先讲一个故事：把英文变中文

我们要解决的，是机器翻译：给它一句英文，让它吐出对应的中文。

2014 年前后，最时髦的做法叫 Seq2Seq（序列到序列），来自两篇同年论文：Sutskever 等人的 *Sequence to Sequence Learning*，和 Cho 等人的 *Learning Phrase Representations*（也就是提出 GRU 的那篇）。它的结构非常朴素，只有两块：

编码器 Encoder
读英文
一个向量 c
全部的理解
解码器 Decoder
写中文

问题就出在中间那个方块上：整句英文，最后被压缩成 一个固定长度的向量。无论句子是 3 个词还是 60 个词，中间这个「快递箱」的大小都一模一样。

打个比方。你要把一整套《三体》三部曲托人带给朋友。但传达室规定：必须把所有内容念给一个传话人听，然后让他只凭记忆复述，而且无论书多厚，他能记住的东西是固定的。 书薄的时候还凑合，到了第三本，他一定会开始漏内容——而且漏的往往是最早听的那部分。
第 ① 章 · 旧办法

一个固定大小的向量，装不下一整句话

这一步最关键：先让你真正体会到「疼」。所以我们先把 RNN 架构拆开看清楚，再来看它为什么一定会痛。

1.1 先把一个词变成一串数字：词向量

在讲 RNN 之前，得先解决一个更基础的问题：计算机不认识 agreement 这个词，它只认识数字。

做法是查表。假设词表里有 3 万个词，我们准备一张 30000 × 512 的大表格 E（叫做词向量表 / embedding 矩阵）。词表里第 k 个词，就对应这张表的第 k 行。要表示句子里的第 t 个词，就查出它的编号，把对应那一行取出来：

xt = E · onehot(wt)　　// 数学上是一次矩阵乘法；实现上就是「查第几行，把那一行取出来」

于是句子变成了 x1 x2 … xT 这样一串长度固定的向量（每个 512 维）。这张表本身也是要学的参数——训练的过程同时也是在学「哪些词的意思比较接近」：学过之后，cat 和 kitten 的向量会靠得很近。

1.2 RNN 单元里到底算的是什么

有了 x1…xT，编码器的工作是把它们揉成「一句完整的意思」。它用的工具就是一个 RNN 单元，最朴素的版本长这样（先别看下标，先看结构）：

ht ＝ tanh( Wx xt ＋ Wh ht−1 ＋ b )

先从最容易被含糊过去的地方开始：这几个字母到底分别是什么东西？把定义钉死，后面就不会看晕。

符号读作它是什么类型 / 形状从哪来
t时间步「第几个词」，从 1 数到 T整数下标—
T句长这句话一共有多少个词整数由输入决定
xt第 t 个输入第 t 个词的词向量——就是 1.1 节查表查出来的那个向量，dx 维（如 512）查 embedding 表
ht第 t 个隐状态读完第 t 个词之后，「到目前为止的全部记忆」向量，dh 维（如 512）由本公式算出来
Wx输入权重矩阵把「输入空间」的说法翻译成「记忆空间」的说法矩阵，dh × dx要学的参数
Wh循环权重矩阵决定「旧记忆」以什么方式影响「新记忆」矩阵，dh × dh要学的参数
b偏置一个常数偏移，让记忆不必被「必须穿过原点」绑住向量，dh 维要学的参数
① 下标 t 是「时间」，不是乘法ht 读作「h 在第 t 个时间步的取值」，不是 h 乘以 t。ht−1 同理，是「上一步的 h」。Wx 里的 x 是下标，表示「这个矩阵是配给 x 用的」。
② h 是一个向量，不是一个数「隐状态 / 隐藏状态」里的「隐藏」，是说它藏在模型内部——不像输入 x 和输出 y 那样你能直接看见。ht 是 dh=512 个数排成的一列，不是一个标量。
③ ht 和 ht−1 不是两个变量它们是同一个变量在两个时刻的快照。每算完一步，新的值就把旧值覆盖掉。可以把它想成一块白板：每读一个词就擦掉重写一次——白板的面积（512 个格子）从头到尾不变。
④ 矩阵的形状是被「加法」逼出来的Wx 必须是 dh×dx、Wh 必须是 dh×dh，否则下面那一步加法根本做不了。看下一段的形状检查。

形状检查：为什么记忆的宽度永远不变

Wx xt　:　(dh × dx) · (dx) ＝ dh　　// 输入被「投影」进记忆空间
Wh ht−1　:　(dh × dh) · (dh) ＝ dh　　// 旧记忆本来就在记忆空间里
两者相加 ＋ b　:　dh ＋ dh ＝ dh　　// 形状一致，才能逐个数相加
tanh( · )　:　dh → dh　　// tanh 逐个元素作用，不改变形状

所以 ht 永远是一个 dh 维向量。请注意最后一行——这就是「信息瓶颈」的数学根源：整个公式里没有任何一个地方能让 h 变宽。句子有 3 个词还是 50 个词，这块白板都只有 dh 个格子。想让模型记住更多，只能换个更大的 dh，而那是有限的。

有了定义，再回头看那三项分别是干什么的：

Wx xt —— 刚听到的刚读到的这个词带来了什么新信息。Wx 是 dh×dx 的矩阵（两者通常都是 512，所以就是 512×512），负责把「词向量空间」里的 xt 翻译成「记忆空间」里的说法。
Wh ht−1 —— 原先记住的上一步攒下来的记忆。Wh 是 dh×dh 的方阵，管的是「旧记忆怎么改写」。请特别注意：能带到下一步的东西，只有 ht−1 这 512 个数，没有别的存档，也没有草稿纸。
＋ 再过一个 tanh —— 揉在一起两部分相加后过一层非线性，把数值压到 (−1, 1)，得到新的记忆 ht。
现代模型把这里换成 LSTM 或 GRU：多几个「门」来决定什么该忘、什么该记，公式更复杂，但 ht 扮演的角色完全一样。

1.4 解码器：另一个 RNN，负责往外写

编码器读完后轮到解码器写。它也是一个 RNN，但有三处不同：输入变成了「上一步自己吐出来的词」、每一步还要额外看一眼 c、而且它用的是另外一整套参数（和解码器的 Wx、Wh 不共享）。

st = f( st−1 , yt−1 , c )　　p(yt) = softmax( Wo st ＋ bo )

逐步拆开：

st−1 —— 解码器自己的记忆注意：它叫 s 不叫 h，因为这是另一个 RNN，参数完全不同。（1.5 节会把 h / s / c 三个符号彻底分清。）
yt−1 —— 上一步吐出来的词第一步还没有词，用一个特殊符号 <sos>（start of sentence）顶上。
Wo 与 softmax —— 从状态到词把 512 维的状态投影成「词表大小」维的分数，softmax 之后就是每个候选词的概率。取概率最大的那个作为输出。
然后把它喂回下一步如此循环，直到吐出 <eos> 结束符。（训练时为了并行和稳定，用的是「教师强制」：直接喂标准答案里的上一个词，而不是模型自己猜的。）

关于 c 怎么进入解码器，两篇 2014 年的论文做法略有差别：Sutskever 把它当作解码器的初始状态（s0 = c，之后就不再出现了）；Cho 则每一步都把它喂进去。但有一点两家完全一样：c 在整个解码过程中是同一个向量，一个数都不会变。记住这句话——这就是 Bahdanau 要掀翻的东西。

1.5 ht 和 c 到底是不是一个东西？

直接回答：在旧的 Seq2Seq 里，c 就是最后一个编码器状态 hT。它们是同一个向量——c 只是它换了个身份之后的新名字。

写成式子就是 c ≡ hT。不是两个东西，也不是「拿 hT 再算出 c」，而是同一块内存，在论文里被赋予了第二个名字。

那为什么要改名？因为视角变了。站在编码器里看，hT 的含义是「读到第 T 个词时我记住了什么」；一旦把它递给解码器，它的含义就变成了「整句话的摘要」。改名是在提醒你：它现在扮演的角色不同了。

但有三件事必须分清楚，否则后面一定会看晕：

① h1 … hT−1 不是 c它们确实被算出来过，但旧模型用完就扔，只留最后一个 hT。这是巨大的浪费，也正是 Bahdanau 要纠正的事。
② 编码器的 h 和解码器的 s 也不是一回事两个独立的 RNN、两套不同的参数。h 是「读」出来的记忆，s 是「写」出来的记忆。
③ 到了 Bahdanau，c 就和 h 脱钩了那时的 ct ＝ Σj αtj hj 是所有 h 的加权平均：它不等于任何一个具体的 h，而且每一步都不一样。这正是下一章的主角。

1.6 问题一：信息瓶颈（Information Bottleneck）

固定维度的向量（比如 512 个浮点数）容量有限。句子越长，需要塞进去的信息越多，而箱子不会变大——于是只能丢。丢掉的往往是句首的信息，因为它在 RNN 里已经被后面很多步「稀释」过了。

1.7 问题二：两个语言的语序对不上

词序不一定一样。英文 the European Economic Area 翻成法文是 la zone économique européenne——形容词跑到了名词后面，顺序整个被打乱。而旧模型要求那一个 c 独力完成所有重排，它没有任何「先看哪、后看哪」的显式机制。

1.8 论文里的证据

这不是猜测。Cho 等人在 2014 年的实验里明确报告：BLEU 分数随着句子变长而下降（BLEU 是翻译质量指标，越高越好）。Bahdanau 的论文里也画了同样的曲线。有意思的是，Sutskever 等人发现：只要把源句子倒着输入给编码器，翻译质量就会明显变好。

为什么倒过来就有用？因为这样句首的词在 RNN 里「走得最短」，最不容易被稀释。这其实是一个很尴尬的补丁——它等于承认了：模型真正需要的，是知道「现在该看原文的哪一段」。而这正是注意力要做的事。

第 ② 章 · Bahdanau 的答案

别只留最后一个记忆，让它每一步都回头扫一眼

Neural Machine Translation by Jointly Learning to Align and Translate
Dzmitry Bahdanau · Kyunghyun Cho · Yoshua Bengio — arXiv:1409.0473（2014 年 9 月，ICLR 2015）

论文标题里的三个词就概括了一切：Jointly（一起）、Learning（学）、Align and Translate（对齐与翻译）。 也就是说：让模型在翻译的同时，自己学出「哪个原文词对应哪个译文词」，而不是把重排这件苦差事统统塞进一个向量里。

2.1 灵感：人是怎么翻译的

你自己翻译这句话的时候，眼睛在干什么？

The agreement on the European Economic Area was signed in August 1990 .
L' accord sur la zone économique européenne a été signé en août 1990 .

写 zone 的时候，你的目光会停在 Area 上；写 août 的时候，你盯着 August。 你不会先把整句死死背下来再闭眼翻译——你一边写，一边在原文上来回扫视。Bahdanau 想做的就是这件事。

2.2 第一步：升级编码器，让每个词都「左右都看得见」

原来的编码器只从左往右读。Bahdanau 用了双向 RNN（biRNN）：一个从左往右读，一个从右往左读，然后把每个位置上两个方向的向量拼起来。

hj = [ →hj ; ←hj ]　　// 第 j 个词的「双向摘要」

于是不再是「只有最后一个状态有用」，而是 h1 … hT 每个位置都留下了一份带上下文的表示。这一步是注意力的地基：没有这些 hj，后面就无从「回头去看」。

演示 5 · 双向 RNN：把鼠标移到任意一个词上
每个词的 hj 都由「它左边的一切」和「它右边的一切」拼成。

2.3 第二步：解码时，每一步都回头「扫一眼」

这是整篇论文的心脏。解码器要生成第 t 个译文词时，做三件小事：

① 打分 etj ② 归一化 αtj ③ 加权求和 ct

① 打分：上一步的我，和原文第 j 个词有多「般配」？

etj = a( st−1 , hj ) = vaT tanh( Wast−1 + Uahj )　 // 一个很小的神经网络，输出一个实数分数

意思是：拿 解码器上一时刻的状态 st−1（我此刻想表达什么）去和 原文每个位置的 hj（原文每个词是什么）逐一比对，得到一个分数。分数越高 = 此刻我越应该看这个位置。

先定一条配色规矩：橙色 = 解码器这一侧的东西，绿色 = 编码器（原文）这一侧的东西，紫色 = 对齐模型自己的、要学的参数。下面一路都用这个规矩，颜色对得上，就说明你找对地方了。

它背后的网络结构：一个只有一层隐层的小 MLP

把公式按数据流画出来，结构其实非常朴素——两条支路各自做一次线性变换，把两边的东西搬到同一个空间里，再相加、过 tanh、最后汇总成一个数：

这个网络的任务只有一个：吃进 st−1 和 hj，吐出一个数 etj。整句翻译里有 T′×T 对 (t, j)，它就要被算 T′×T 次。

其中相加那一步是逐元素相加（对应位置的数两两相加，得到 n 个数），tanh 也是逐个数作用。所以整条链路从头到尾都是 n 维、n 维、n 维……只在最后 vaT 那一下才塌缩成 1 个数。

tanh( Was + Uah ) ＝ tanh( [ Wa | Ua ] · [ s ; h ] )　　// s 和 h 首尾拼起来，两个矩阵也并排放
所以它其实就是一个标准的前馈神经网络，只不过入口处被「劈」成了两半。

把 st−1（n 维）和 hj（2n 维）首尾拼成一个 3n 维向量喂进去：

· 隐层：n 个神经元，激活函数是 tanh，没有偏置；
· 输出层：只有 1 个神经元，权重就是 va；
· 输出：一个实数 etj。
论文给这个网络起的名字就是 alignment model（对齐模型）。所谓「学对齐」，学的就是这三个参数里的每一个数。

为什么要 tanh？如果拿掉它，vaT(Was + Uah) 会合并成一次纯线性的打分——表达能力约等于「把两个向量各自投影一下再点积」。加上 tanh 之后，模型才有能力表达「只有某种组合出现时才给高分」这类非线性的匹配条件。
为什么最后要 vaT？tanh 之后拿到的是 n 个数，每个维度都在描述「哪方面像」。这 n 个数需要被汇总成 1 个分数才能做 softmax。点积就是最简单的汇总方式：给每一维配一个权重，然后加起来。va 就是那组权重，也是学出来的。

va 是怎么来的？——它不是额外零件，是「1 个输出神经元」的必然产物

很多人第一次看到这条式子，会卡在最后那个 vaT 上：前面两条支路还看得懂，这东西是哪儿冒出来的？把它倒过来推，其实只有三步：

第 1 步 · 出口规定了形状etj 接下来要被丢进 softmax。softmax 只吃一个数。所以不管打分函数内部多复杂，它的输出必须是标量——这是一条硬约束。
第 2 步 · n 个数 → 1 个数tanh 吐出来的是 n 个数 u。要把 n 个数折成 1 个数，最一般的可学习线性汇总只有一种写法：w₁u₁+w₂u₂+…+wₙuₙ，也就是 wTu。
第 3 步 · 给它起个名字论文把这组汇总权重 w 命名为 va，并省掉偏置 b。于是就有了 etj = vaTu。
etj = vaT u　　// u = tanh(Wast−1 + Uahj)，n 维
形状检查　(1 × n) · (n × 1) = (1 × 1)　　// 一次点积 = 加权求和 = 塌缩成一个数
所以 va 就是「输出层那 1 个神经元的权重」。

任何「让神经网络输出一个标量」的地方，都必然有这样一组权重。它不是 Bahdanau 额外加上的零件，而是这个结构里躲不掉的一环：隐层给出 n 个数，输出层只有 1 个神经元，连接它们的就是 n 条边——那 n 条边的强度，就是 va。

打个比方：u 是「这一对 (t, j) 的表现单」，va 是「阅卷细则」。u 的 n 个维度就像 n 项考察点，每个维度上的数值表示「这一对在这一点上表现如何」（可正可负）；va 里的 n 个数则是「每一项占多少分、是加分还是扣分」。打分 ＝ 按细则给表现单打分。

关键在后面这一句：同一份 va 被用在所有 (t, j) 上。它不是某一对的数据，而是一套通用的匹配标准——模型学的就是「什么样的 s 和 h 组合算般配」。对比一下 Transformer：那里的 q 随 t 变、k 随 j 变，而 Bahdanau 的 va 谁也不随，它就是那个被学出来的标准本身。

va 的长度要自己选吗？不用。它的长度 ＝ 打分空间的维度 n，而 n 是 Wa 的输出宽度决定的。定了 Wa，va 的长度就跟着定了——三个参数是长在一起的。
上标 ᵀ 到底在干嘛？纯粹是书写约定：列向量转成行向量才好写乘法。vaTu 和点积 ⟨va, u⟩ 是同一件事。要是写成 vauT，那就变成 n×n 矩阵了——完全是另一个东西。
为什么它跟 t、j 都无关？因为它是标准，不是数据。如果 va 也随位置变，模型就不是在「学一种匹配方式」，而是在「背每一对的答案」——参数会爆掉，也泛化不了。

追问：解码的时候，va 是固定的吗？

是——va 训练完就被彻底冻结，解码全程一个数都不变。

这里要分清两类东西：参数（Wa、Ua、va，以及两个 RNN 的全部权重）只在训练时被梯度更新；状态（st−1、hj、etj、αtj、ct）是解码时才现算出来的。va 属于前者，所以它不随 t 变、不随 j 变，换一个句子也不变。

解码过程中的东西属于同一次翻译里换一个句子
Wa / Ua / va参数固定，一个数都不变也固定（所有句子共用同一套）
h1 … hT编码结果固定：编码一次，全程复用随句子变
st−1解码状态每步都变——这才是「随 t 变」的那一半随句子变
etj / αtj / ct当场算出的中间量每步重算随句子变

所以准确的说法是：打分标准（va）是固定的，被比较的对象（st−1）才是变的那一方。同一把尺子，每一步去量不同的东西——这就是前面说的「一套通用标准」的实际含义：所谓「注意力学会了看哪里」，学的是这把尺子，不是每一步的答案。

顺带一个很实用的推论：既然 Uahj 里既不含 st−1、也不含 t，它就可以在解码开始前一次算好、缓存起来；之后每一步只需要算 Wast−1，再相加、过 tanh、与 va 做点积。「va 与 t 无关」这件事，直接换来了一个可预计算的缓存。

跟 Transformer 对照着看会更清楚。Transformer 里的 WQ、WK、WV 同样是固定参数，但它把「我此刻想找什么」从状态搬进了数据：每个位置都用同一套 WQ 乘出自己的 q。于是 q 随位置变、k 随位置变——好处是所有分数能凑成一次矩阵乘法 QKT，代价是每换一个句子、每换一层，这套投影都得重算一遍。 一边用「打分权重固定」换来缓存，一边用「投影固定、向量可变」换来并行。

那「不同词之间的权重不同」这件事，是谁在负责？

这是一个非常关键的疑问：va 固定死了，怎么还能表示不同词之间千差万别的权重关系？答案其实是一句改名字的话：你说的那个「随词而变的东西」确实存在，只是它不叫 va，它叫 αtj。

层次具体是谁训练完之后换成别的句子
规则层 · 参数Wa、Ua、va冻结，一个数不变不变（共用同一套）
对象层 · 输入st−1、h1…hT—全变
结论层 · 现算etj → αtj → ct—全变：每一对 (t, j) 都不相同

「不同词之间的权重关系」属于第三层。原文 14 个词、译文 14 个词，就有 14×14 ＝ 196 个 αtj，它们各不相同、随句子而变——你想要的东西一个都没少。第一层的 va 只负责规则：拿什么标准去打分。

尺子不用变，量出来的长度照样各不相同一把刻度固定的尺子，量桌子和量铅笔会给出不同的数——因为被量的东西不一样。etj 里「被量的东西」是 st−1 和 hj，它们每一步、每个位置都在变。
别忘了：整个模型的参数都是固定的Wx、Wh 也是固定的——可就是这一套固定的参数，读得懂任何句子。如果「参数固定就表达不了差异」成立，那 RNN 连一句话都读不懂。变化来自输入，不来自参数，这是神经网络最基本的约定。

再举一个更极端的例子：哪怕把 tanh 整个拿掉，让打分退化成一次纯线性的双线性形式，每一对词照样能得到不同的分数。Transformer 走的就是这条路：

etj = qt · kj = xtT ( WQTWK ) xj　　// 括号里的比较矩阵固定不动，变的是两边乘进去的 x

看仔细：WQTWK 是一个训练完就冻死的矩阵，它就是 va 在乘法式注意力里的对应物；可 qt、kj 每个位置都不一样，于是每个 etj 都不一样。固定的是「怎么比」，变化的是「比谁」——这两件事从来不在同一个地方。

最后补一句：如果真想让「比较规则本身」也随输入而变，那是另一条路（条件计算，或多头注意力里让不同的头学不同的规则）。但即便在那种模型里，参数依旧是固定的，随输入变的始终是中间算出来的那些张量。

可它为什么要写得这么绕？跟点积有什么不一样

Bahdanau 用的：加法式（additive）先把两边各自投影到同一个 n 维空间再相加，中间还夹了一层非线性。好处是不要求 s 和 h 的维度相同，表达能力也更强；代价是慢（见下）。
Transformer 用的：乘法式（multiplicative）直接 q·k 点积打分。要求两边维度一致，但干净到可以写成一次矩阵乘法 QKT，一次把所有分数全算完。这正是第 4 章要讲的转变。

这两类后来被 Luong 等人在 2015 年的论文里正式命名并做了对比。Bahdanau 选了「用算力换表达力」，Transformer 选了「用表达力换并行」——你在第 4 章看到的 QKT/√dk，就是这条路线上的终点。

代价：为了打分，要付多少

参数：3n² + n 个Wa 是 n×n＝n² 个，Ua 是 n×2n＝2n² 个，va 是 n 个。以 n＝1000（论文量级）为例，光这个「打分小网络」就要背 约 300 万个参数——和整个编码器一个量级。
计算：T′ × T 次前向每写一个译文词（共 T′ 步），都要和原文的每一个位置（共 T 个）算一次这个小网络。原文 50 个词、译文 50 个词，就是 2500 次。而且这 2500 次只能一次一对地算，凑不成一次大矩阵乘法。

记住这两个数字——它们解释了三年后 Transformer 为什么要动手改掉这个打分方式。

论文自己的说法：这个对齐模型不是单独预训练的，也不是人工标注的，而是和其他所有部件一起训练的；梯度可以穿过打分函数直接回传。 这就是标题里 Jointly Learning to Align and Translate（联合学习对齐与翻译）的字面含义——对齐不是副产品，它是被翻译这个目标「逼」出来的。

② 归一化：把一堆分数变成一堆权重

αtj = exp(etj)Σk=1..T exp(etk) 　　// softmax，让所有权重为正且加起来等于 1

得到的 αtj 就是「注意力权重」。它可以是 0.7、0.2 这种含义清晰的数：这次我要 70% 看第 3 个词，20% 看第 7 个词。这被称为软对齐（soft alignment）——不硬性指定「一对一」，而是允许同时看几个地方。

③ 加权求和：现场调制一杯「本次专用的上下文」

ct = Σj=1..T αtj hj 　　// 按权重把原文所有位置的信息混合成一个向量

然后再用这个 ct 和 st−1 算出新的解码状态 st，并预测出这个词。用公式串起来就是：

st = f( st−1 , yt−1 , ct )　　p(yt | …) = softmax( g( st , yt−1 , ct ) )
整个论文的转折点就在这个下标 t 上。旧模型用的是 c——一个从头到尾不变的向量。 Bahdanau 用的是 ct——每写一个词都重新算一次的向量。
这一个下标，就是「瓶颈」和「注意力」的全部分界线。

第 ③ 章 · 新的枷锁

注意力很聪明，但它坐在一个很慢的引擎上

Bahdanau 的注意力是挂在 RNN 上的一个附件。而 RNN 本身，有一个改不掉的天性。

3.1 RNN 必须「一个一个来」

看这个公式：ht = f(ht−1, xt)。第 5 个词的隐藏状态，必须等第 4 个算完才能开始算。这句话的潜台词是：句子有 50 个词，就必须老老实实走 50 个串行步骤。

GPU 最擅长的恰恰是「同时做一万件互不依赖的事」。可 RNN 偏偏把它变成了一场接力赛——跑道上有再多人也只能排队。这带来三个后果：

第 ④ 章 · Transformer

既然「回头看一眼」这么好用，能不能只要它？

Attention Is All You Need
Vaswani 等 8 人 · Google Brain / Google Research — arXiv:1706.03762（2017 年 6 月，NeurIPS 2017）

这篇论文标题起得极为嚣张，也极为准确：你需要的，只有注意力。它把 RNN 整个删掉，让每个词直接「看到」句子里的所有其他词。

可是删掉 RNN 会撞上一个硬问题：

Bahdanau 的注意力里，query（那个「我要找什么」）是 st−1——解码器 RNN 的状态。 RNN 没了，query 从哪来？

Transformer 的回答漂亮极了：从句子自己身上来。原文的每个词，自己生成一个 query，去问同一句话里的其他所有词。这叫自注意力（Self-Attention）：一句话自己问自己。

4.1 那 Q、K、V 到底是什么？

先把三个概念用生活场景说清楚。假设你在一个超大的图书馆里找资料：

Query（查询）· Q

「我要找什么」——你手里拿的那张纸条，写着你的需求。

在句子里：我读到「它」，我想搞清楚「它指的是谁」。
Key（键）· K

「我这儿挂什么标签」——每本书书脊上的分类标签，用来被检索、被比对。

在句子里：每个词举一块牌子：「我是水果」「我是动词」「我是代词」。
Value（值）· V

「我这儿实际有什么内容」——真正被取走、被带回家的那部分信息。

在句子里：一旦匹配上「苹果」，就把苹果的语义内容搬过来，用来理解「它」。

注意力和「翻字典」的区别：字典要求 query 和 key 完全相等才有结果；注意力里 每个 key 都返回一个分数，最后按分数高低把所有 value 混合起来——这就是「软」的含义。

4.2 关键一步：Q/K/V 是从 Bahdanau 的公式里自然长出来的

这是全文最值得慢慢读的一段。我们不凭空发明 QKV，而是从 Bahdanau 的公式出发，看它怎么一步步被改造成 Transformer 的样子。

起点 · Bahdanau 的注意力

etj = a( st−1 , hj )　；　αt· = softmax(et·)　；　ct = Σj αtj hj

「解码器的状态」去比「每个源词的编码」，然后加权取走「每个源词的编码」。

改动 ①：把「解码器问编码器」变成「句子内部互相问」

既然没有 RNN 提供 st−1，那就让句子里的每个词都发一张查询纸条。第 i 个词用它自己的表示 xi 当 query，去和所有位置的表示比对。于是「一对多」（解码器 → 编码器）变成了「多对多」（每个词 → 所有词）。这就是自注意力。

改动 ②：把「打分用的向量」和「取走用的向量」拆开

这一步最容易被忽略，但它是 K 和 V 存在的根本原因。

在 Bahdanau 里，第 j 个词参与了两件事，用的是同一个 hj：
（a）被当作「靶子」来打分（我要不要看它）；
（b）被当作「内容」加权取走（我从它那儿拿点什么）。

问题是，这两种需求是冲突的。为了让检索更准，我们希望一个词把「我是什么」标记得夸张、鲜明（像一个醒目的标签）；但作为内容被取走时，我们又希望它保留原汁原味的完整信息。一个向量要同时胜任两职，只能折中。

解决办法：一个词派出两个代表——Key 专门负责「我是谁，方便被找到」，Value 专门负责「我有什么，方便被取走」。而查询方也单独派一个代表 Query：「我此刻想找什么」。

于是：Q 和 K 决定「看哪里」，V 决定「拿走什么」。这就是三个向量的分工，也是名字的由来。

改动 ③：用最便宜的运算来打分——点积

Bahdanau 的 a(·,·) 是一个带 tanh 的小神经网络，每一对 (i, j) 都要单独前向一遍，很贵。既然 Q 和 K 已经是分开的向量了，那「有多般配」这件事，最自然的衡量方式就是点积——两个向量方向越一致，内积越大，而且一次矩阵乘法能同时算出所有对。

eij ≈ qi · kj　　 // 从「小神经网络」换成「一次点积」：更简单，而且能并行

改动 ④：去掉循环，直接从词向量线性映射出 Q/K/V

qi = WQ xi　　 kj = WK xj　　 vj = WV xj 　// 三个可学习的投影矩阵，作用在每个词上

把一句话的所有词向量堆成一个矩阵 X，那就变成 Q = X WQ、K = X WK、V = X WV——三次矩阵乘法，一次算完一整句。没有第 t 步依赖第 t−1 步这回事了。这就是并行性的来源，也是 Transformer 能长大的原因。

终点 · 缩放点积注意力

Attention( Q , K , V ) = softmax( QKT√dk ) V
QKT — 打分一句话里 T 个词，两两打分得到 T×T 的分数矩阵。它和 Bahdanau 那张对齐热图是同一个东西，区别只在于：那时候是一次算一格，现在是整张表一次算完。
÷ √dk — 缩放维度 dk 越大，点积的数值越大、方差越大，softmax 会被推到「几乎 one-hot」的饱和区，梯度趋近于 0（学不动）。除以 √dk 把方差拉回 1 附近。这是工程上的救命细节。
softmax — 归一化让每一行的权重非负且和为 1，得到「每个词应该看哪些词、分别看多少」。和 Bahdanau 的 α 完全同义。
× V — 取值用权重对 V 做加权求和。这就是 ct = Σ αtjhj 的推广，只不过是所有位置同时完成。
一句话总结这段推导：Bahdanau 发明了「按相似度加权混合信息」。Transformer 做了三件事—— 把提问方换成句子自己（自注意力）、把「被打分」和「被取走」拆成 K 和 V、把配对方式换成可并行的点积。 Q、K、V 不是三个凭空规定的新符号，它们是把 Bahdanau 的注意力「拆开重装」之后的零件。

4.4 多头注意力：同时用好几双眼睛看

一个注意力只能学到一类关系。可是语言里的关系是重叠的：谁修饰谁（语法）、谁指代谁（语义）、谁紧挨着谁（位置）、谁和谁押韵（语音）……

Transformer 的做法很直接：并行跑 h 个（论文里是 8 个）独立的注意力，每个头有自己的一套 WQ/WK/WV，各自关注自己想关注的东西；最后把 8 个输出拼起来，再乘一个矩阵融合。

headi = Attention( XWQ(i) , XWK(i) , XWV(i) )　；　MultiHead = Concat(head1,…,head8) WO

每个头的维度被压小到 dmodel/h，所以 8 个头的总计算量和 1 个全维度的头差不多——是「多视角」而不是「多花 8 倍」。

4.5 位置编码：把丢掉的东西补回来

自注意力有一个「副作用」：它本质上是在一个集合上做加权平均。把句子里的词打乱顺序，注意力的计算结果几乎不变（这叫置换等变）。可「猫追老鼠」和「老鼠追猫」完全是两回事。

RNN 天生带顺序（一步一步走），Transformer 没有，所以必须显式地把位置信息加进词向量里：

PE(pos, 2i)　 = sin( pos / 100002i/d )
PE(pos, 2i+1) = cos( pos / 100002i/d ) 　// pos = 第几个词，2i/2i+1 = 向量里的第几维

然后把 xi + PE(i) 作为真正的输入。为什么用正弦余弦？因为不同频率的正弦波能唯一地编码位置，而且「往后移 k 个位置」相当于对某个频率做一次固定角度的旋转——模型因此容易学会「相对距离」。

图 3 · 位置编码长什么样
横轴 = 维度（0→63）· 纵轴 = 位置（0→95）· 颜色 = 数值（橙正 / 蓝负）
从上往下读同一列（固定一个维度、看它在不同位置上的取值）：最左边几列飞快地正负交替， 负责区分相邻位置；越往右变化越慢，负责区分句子的远段。 把一行横着读下来，就是每个位置独一无二的「指纹」。（虚线框出的第 1 维是在提示你「列」该怎么读；相邻两列是一对 sin / cos。）

4.6 忘了 RNN，可没有丢掉 Bahdanau

Transformer 的完整结构里，解码器其实有两种注意力层，它们各自分工：

① 自注意力（Self-Attention）Q、K、V 全来自同一句话。
编码器：让英文句子内部互相看。
解码器：让「已生成的译文」内部互相看。
② 交叉注意力（Cross-Attention）Q 来自解码器（译文），K 和 V 来自编码器（原文）。
请仔细看这一行——这就是 Bahdanau 的注意力：解码器用自己的状态去检索原文的所有位置。

角色完全一样，只是打分方式从「小神经网络」换成了「缩放点积」，并且不再依赖 RNN 逐步推进。

另外，解码器必须做一件事：掩码（Masking）。训练时为了并行，我们把整句译文一次性喂进去，但生成第 3 个词时绝不能偷看第 4 个词。做法是把分数矩阵的右上三角设成 −∞，softmax 之后权重自然变成 0。

4.7 结果与影响

🏆 分数更好WMT'14 英德达到 28.4 BLEU（big 模型），比当时最好的结果高出 2 个点以上，而训练成本只是它的一小部分；英法也创下当时最佳。
⚡ 快得多训练成本大幅下降：base 模型只用 8 块 P100 训练 12 小时就超过了此前最好的结果（big 模型也只要 3.5 天）。
🌱 长出了后来的一切可并行 + 可堆叠 = 可以让模型变巨大。BERT（只用编码器）、GPT（只用解码器）都建立在同一个模块上。
回头看这条线很清晰：RNN 把整句话压成一个向量 → 信息不够 → Bahdanau 让解码器回头扫一眼（发明注意力）→ 但 RNN 太慢 → Transformer 干脆只留注意力，并把它拆成 Q（我要找什么）、K（我是谁）、V（我有什么） → 于是能并行、能堆深、能变大。
