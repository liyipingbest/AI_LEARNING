导读 · The through-line

一条主线：压缩 → 检索 → 只保留检索

这三个模型不是三套互不相干的技巧，而是同一条问题链上的三次回答。先记住这条链，后面的公式就不会散。

想象你要把一句英文翻译成中文。你读英文时，不会把每个词抄在一张纸上；你会在脑子里形成一个“意思”，然后一边写中文，一边回想英文原句的相应部分。问题在于：“意思”要存在哪里？以什么形式存在？写每个词的时候，又怎么把它取出来？

2014 年的 seq2seq 给出的答案是：让编码器 RNN 读完整个句子，把全部信息压进最后一个隐藏状态 c，解码器只从这个 c 里往外写。这很优雅，也很脆弱——句子一长，c 就变成了一只装不下的箱子。

2015 年的 Bahdanau 注意力说：别压了。编码器把每个位置的表示都留着，解码器每写一个词，就拿着当前状态去和原文每个位置打分，按权重把需要的信息取回来。信息不再经过一个狭窄的瓶口，而是可以按需检索。

2017 年的 Transformer 再往前一步：既然“打分—加权—取回”这么好用，为什么还要用 RNN 来产生“当前状态”？让句子里的每个词自己发问、自己回答，把所有位置一次性两两比较——于是唯一的主干就只剩注意力。

Stage 1 · 1986–2014

RNN：顺序地记

同一个单元沿时间复用，隐藏状态是记忆。表达能力强，但必须一步一步算，长距离信息会被反复覆盖。

Stage 2 · 2014/15

Attention：按需地取

保留每个源位置的表示，解码时动态打分、加权求和。瓶颈被打开，还能看见对齐。

Stage 3 · 2017

Transformer：并行地查

把“问—配—取”拆成 Q/K/V，用矩阵乘法一次算完所有位置，彻底移除循环。

先把时间线校准

Bahdanau、Cho、Bengio 的论文 Neural Machine Translation by Jointly Learning to Align and Translate 于 2014 年 9 月挂上 arXiv，2015 年在 ICLR 作为 oral 发表，所以常被称作“2015 年的注意力机制”。Luong 等人的点积/乘性注意力同样发表于 2015 年。Transformer 的论文 Attention Is All You Need 于 2017 年 6 月公开。本文按“2015 注意力 → 2017 Transformer”叙述，但会把 2014 年的 seq2seq 作为必要的起点。

怎么读这篇讲义

01
Stage 1 · 1986 – 2014

RNN：把整段时间折进一个向量

在注意力出现之前，序列建模的主流答案是“循环”：用同一个单元沿时间反复计算，让隐藏状态充当记忆。它解决了变长输入，却也埋下了三个隐患——信息被反复覆盖、语序难以对齐、计算被时间锁死。

1.1 为什么需要“循环”

把一句话送进神经网络，第一件麻烦事是长度不固定。“猫睡觉”是三个词，“昨天下午那只橘猫在窗台上睡了一觉”是十几个词。用全连接网络，你得先把句子变成固定长度的向量；最粗暴的做法是词袋（bag of words）——把所有词向量加起来。

词袋丢掉了顺序。“猫追老鼠”和“老鼠追猫”的词袋完全一样，但意思相反。要保留顺序，最自然的想法是：按顺序读，读到一个词就更新一次记忆。这就是循环神经网络（Recurrent Neural Network, RNN）的核心。

ht = tanh( Wh ht−1 + Wx xt + b )
(1.1)

读法：新的记忆 = 对“旧的记忆”和“当前输入”各做一次线性变换，相加，再过 tanh。所有时间步共用同一组 Wh、Wx、b。

形状很重要：若词向量 xt ∈ ℝd，隐藏状态 ht ∈ ℝn，那么 Wx ∈ ℝn×d，Wh ∈ ℝn×n，b ∈ ℝn。注意：参数量与句子长度无关。处理 5 个词和处理 50 个词，用的是同一个单元。这就是“参数共享”的好处，也是 RNN 能推广到任意长度的原因。

把图 1 横着看，h1 影响 h2，h2 影响 h3……最后一个状态里，理论上含着整句话的信息。但“含着”不等于“取得出来”：每经过一次变换，旧信息就被新输入稀释一次。这就是后面所有问题的源头。

1.2 训练它：一条越走越细的梯度

RNN 的训练叫“沿时间反向传播”（Backpropagation Through Time, BPTT）：把图 1 当成一个很深的前馈网络，沿时间反着求梯度。问题出在链式法则的连乘上。以第 T 步的损失对第 1 步状态的梯度为例：

∂L/∂h1 = ( ∂L/∂hT ) · ∏t=2T ( ∂ht/∂ht−1 )
(1.2)

每一个 Jacobian ∂ht/∂ht−1 里都含一个 Wh⊤ 和 tanh 的导数（≤ 1）。如果 Wh 的谱半径小于 1，连乘会指数级趋近 0——梯度消失，前面的词学不到；如果大于 1，又会指数级爆炸——梯度爆炸，训练发散。句子越长，连乘的项越多，问题越严重。

注意：这不是“实现细节”

梯度消失意味着模型结构上很难学会“第 1 个词和第 20 个词有关系”。即使 LSTM 缓解了它，信息仍然要沿时间一步步传递，路径长度是 O(n)。这一点会在 Transformer 里被彻底改写：任意两个位置的路径长度变成 O(1)。

LSTM 的补丁：给梯度开一条加法通道

1997 年的 LSTM 用“门”控制信息的写入、保留和输出。核心是 cell state ct：它不再每一步都被彻底重写，而是通过逐元素乘法和加法更新。

ft = σ(Wf[ht−1; xt] + bf)    遗忘门：旧记忆留多少
it = σ(Wi[ht−1; xt] + bi)    输入门：新信息写多少
ct = ft ⊙ ct−1 + it ⊙ tanh(Wc[ht−1; xt] + bc)
ot = σ(Wo[ht−1; xt] + bo)    输出门：这一刻露出多少
ht = ot ⊙ tanh(ct)
(1.3)

关键在第三行：ct−1 到 ct 是一条逐元素乘法 + 加法的路径，而不是“矩阵乘 + tanh”的反复挤压。当遗忘门接近 1 时，梯度可以几乎原样地沿这条路径回流。它没有把路径变短，但把“连乘”变成了“连乘几个门”，让长距离信息更容易存活。

1.3 seq2seq：两台 RNN 的接力

有了能读句子的编码器，机器翻译可以写成“编码—解码”（encoder–decoder）：编码器 RNN 读入源句，把最后一个隐藏状态 hT 当作整句的摘要 c；解码器 RNN 从 c 出发，一个词一个词地生成译文。

c = hT(enc)
st = f(st−1, yt−1, c)
p(yt | y<t, x) = softmax(Wo st + bo)
(1.4)

训练时，解码器每一步的输入是“标准答案的上一个词”（teacher forcing），整句可以并行算损失；推理时没有标准答案，只能把上一步的输出喂回去，逐词生成。这个“训练并行、推理串行”的不对称，会一直保留到 Transformer——只是 Transformer 把训练时的并行度从“按词”提升到了“按层”。

1.4 三个硬伤，逼出了下一步

Hard problem 1

信息瓶颈

c 的维度固定，句子越长，平均每个词分到的“容量”越少。Cho 等人 2014 年的实验显示，基础 encoder–decoder 的 BLEU 会随句长增加明显下滑。

Hard problem 2

语序不对齐

两种语言的词序并不一一对应（法语形容词常在后，中文“把”字句等）。一个定长向量很难同时记住“内容”和“该放到哪”。

Hard problem 3

无法并行

ht 依赖 ht−1，第 100 个词必须等前 99 个算完。GPU 擅长的大矩阵并行在这里失效，训练和推理都被时间步锁住。

前两个问题指向同一个念头：别再把整句话压成一个向量，让解码器自己决定每一步该看哪里。这就是注意力。第三个问题当时还不是最痛的——直到人们发现，注意力的计算可以完全不需要循环。

第一章留下的账

解决了：变长序列的建模、参数共享、顺序信息的隐式编码。
没解决：定长瓶颈、长距离依赖的梯度路径、时间步带来的串行计算。下一章先解决前两个。

02
Stage 2 · 2014 预印 / 2015 ICLR

Bahdanau 注意力：别压了，每步回头查一次

如果解码器在写每个词时，都能重新决定“现在该看原文的哪几个位置”，那它就不需要把整句话塞进一个向量。这个念头把“对齐”从一个隐变量变成了一个可微的加权求和。

先回到翻译现场。假设原文是 The cat sat on the mat，你要生成中文“猫 坐 在 垫子 上”。写“猫”的时候，你最该看的是 cat；写“坐”的时候，最该看的是 sat；写“垫子”的时候，才轮到 mat。也就是说，解码的每一步，关注的源位置是不同的。

seq2seq 的固定向量 c 无法表达这种“因步而异”。Bahdanau 的改动可以概括成一句话：编码器不再只交最后一个状态，而是把每个位置的表示都留在桌上；解码器每一步自己过来挑。

2.1 第一步：让每个词的表示“左右都看得见”

如果编码器只从左往右读，那么 hj 只见过 x1…j，不知道右边还有什么。可翻译一个词时，后面的词往往同样重要。比如英文的形容词和名词、中文的“把”字句，单看左边会误判。

于是 Bahdanau 用双向 RNN（BiRNN）做编码器：一个方向从左往右，另一个从右往左，最后把两个隐藏状态拼起来。

→hj = f→(xj, →hj−1)
←hj = f←(xj, ←hj+1)
hj = [ →hj ; ←hj ]   ∈ ℝ2n
(2.1)

这里的 hj 在论文里叫 annotation（注解）：它不再只是“读到第 j 个词时的记忆”，而是“围绕第 j 个词、融合了左右两侧上下文的一段摘要”。这一点很关键——注意力的“键”和“值”，从此有了独立的、逐位置的载体。

先记住这个结构

BiRNN 仍然是循环的，仍然要一步一步算。它解决的是“每个位置都有表示”，不是“并行”。真正把 RNN 拿掉，要等到 2017 年。

2.2 第二步：打分、归一化、加权求和

解码器在生成第 t 个词之前，手上有上一时刻的状态 st−1。它想回答一个问题：“以我现在的状态，原文的每个位置和我有多匹配？” 对每个源位置 j，先算一个未归一化的分数：

etj = a(st−1, hj) = va⊤ tanh( Wa st−1 + Ua hj )
(2.2)

这个 a(·,·) 就是论文里的 alignment model（对齐模型）。它其实是一个只有一层隐层的小型前馈网络：两条支路分别把 st−1 和 hj 线性变换到同一个 n 维“打分空间”，逐元素相加，过 tanh，再用 va 加权求和成一个标量。

为什么用 tanh

如果没有非线性，va⊤(Was + Uah) 会塌缩成一次线性打分，表达能力接近“各自投影后点积”。tanh 让模型能表达“只有某种组合出现时才给高分”这类非线性匹配。

为什么最后要 va⊤

tanh 输出的是 n 个数，但每个 (t, j) 对最终只能贡献一个分数，softmax 是在这 Tx 个分数上做的。要把 n 个数折成一个标量，最一般的可学习线性汇总就是按一组权重相加，即 va⊤u。它不是额外零件，而是“输出层只有一个神经元”的必然产物。

得到所有 etj 后，在源位置方向做 softmax，得到一组和为 1 的权重：

αtj = exp(etj) / ∑k=1Tx exp(etk)
(2.3)

最后，用这组权重把编码器的所有 annotation 加权求和，得到这一步专用的上下文向量：

ct = ∑j=1Tx αtj hj
(2.4)

解码器随后把 ct、上一步状态 st−1 和上一个词 yt−1 一起送进 RNN，更新状态并预测当前词：

st = f(st−1, yt−1, ct)
p(yt | y<t, x) = softmax(Wo st + bo)
(2.5)

把这三步连起来看：打分回答“看哪里”，softmax 回答“各看多少”，加权求和回答“取回什么”。它不是硬性地把某个源词指给某个目标词，而是让模型自己学出一张软对齐（soft alignment）——每个目标位置对所有源位置都有一票，只是权重不同。

为什么不用点积？

st−1 是 n 维，hj 是 2n 维，维度不同，不能直接点积；即使用矩阵把它们投影到同一维，未缩放的点积在维度较大时也容易数值不稳。加性注意力用 Wa、Ua 把两边投到同一个打分空间，再用 tanh 学非线性匹配——代价是每个 pair 都要跑一次小 MLP。这个代价，正是 Luong 后来要优化的地方。

三个容易看漏的细节

① softmax 是在源位置 j 的方向做的，每一行目标位置各自归一化；② ct 的维度是 2n，因为 hj 是双向拼接的；③ 对齐模型没有偏置项，这不是笔误，而是论文的原样写法。

2.5 它到底解决了什么

最直接的变化是：信息不再必须挤过一个固定维度的向量。编码器保留 Tx 个 2n 维的 annotation，解码器每一步用一组权重去取。源句变长，可用的“存储单元”跟着变多，而不是被压进同一个 c。

第二个变化在梯度上。ct = ∑j αtjhj 是一条直接的加权和：损失对某个 hj 的梯度，至少有一条路径只经过一个系数 αtj，而不是穿过 T 个时间步的连乘。编码器内部仍然有循环，但“解码器要用第 1 个词的信息”这件事，不再需要沿解码时间步一步步传递。

2.6 代价：聪明，但仍坐在慢引擎上

Bahdanau 的注意力是一次漂亮的修补，但它没有动 RNN 本身。三个限制原封不动地留着：

Limit 1

解码仍然串行

st 依赖 st−1，第 t 个目标词必须等前一个算完。即使训练时有 teacher forcing，RNN 的状态递推仍然沿时间串行。

Limit 2

编码仍然串行

BiRNN 的两个方向各自都是循环的，hj 依赖 hj−1（或 hj+1）。长句的编码时间随时长线性增长。

Limit 3

打分很贵

每个 (t, j) 都要跑一次带 tanh 的小 MLP，TyTx 次前向无法合并成一次大矩阵乘法；长句的注意力开销是二次的。

于是问题变成了：能不能保留“打分—加权—取回”的语义，但把产生 query 的循环、产生 key/value 的循环、以及打分的 MLP 全部换掉？ 2015 年 Luong 的工作先把打分换成了更便宜的点积；2017 年的 Transformer 则把整个循环拿掉。

第二章留下的账

解决了：固定向量瓶颈、长句性能衰减、对齐的可解释性、到源位置的一条短梯度路径。
没解决：训练/推理的串行性、二次打分成本、注意力仍只是 RNN 的附件。

03
Bridge · 2015

Luong 注意力：把打分变便宜，把方向指向矩阵乘法

Bahdanau 用一个小神经网络打分；Luong 证明，很多情况下一次点积就够了。这个看似工程化的简化，正好是 Q/K/V 的前身。

2015 年，Luong、Pham、Manning 发表了 Effective Approaches to Attention-based Neural Machine Translation。这篇论文没有推翻 Bahdanau，而是把注意力拆成几个可以独立替换的部件，系统比较了“怎么打分”“看多大范围”“怎么把上一步的注意力喂回去”。其中最重要的遗产，是点积打分。

3.1 全局看，还是只看一扇窗

Global attention 和 Bahdanau 一样，对源句所有位置打分。它的上下文向量是：

ct = ∑j αtj hj    αtj = softmaxj( score(st, hj) )
(3.1)

Local attention 则先预测一个对齐中心 pt，只在 [pt−D, pt+D] 的窗口内打分。这样每步的注意力开销从 O(Tx) 降到 O(D)，对长句更友好。代价是窗口可能错过真正相关的词，而且 pt 本身要学。

3.2 三种打分函数：从 MLP 到点积

形式打分函数维度要求计算
dotst⊤ hjst 与 hj 同维一次内积，最便宜
generalst⊤ Wa hj可不同维，Wa 负责对齐一次双线性型
concatva⊤ tanh(Wa[st; hj])无小 MLP，最贵（Bahdanau 式）

Luong 的实验发现：在当时的设置下，dot 和 general 的效果与 concat 相当，但快得多。原因很直接：dot/general 可以写成矩阵乘法，而 concat 必须对每一对 (t, j) 单独跑一次非线性网络。注意这里有一个前提：点积的数值会随维度增大而变大，维度很高时 softmax 容易饱和；后来的 Transformer 用 1/√dk 显式解决了这个问题（下一章会推导）。

3.3 一个被低估的工程细节：input feeding

Luong 还提出 input feeding：把上一步的注意力向量与当前输入拼接，一起喂给解码器。一种简化写法是：

st = f( st−1, [ yt−1 ; ct−1 ] )
(3.2)

这让解码器“知道自己上一步看了哪里”，避免每一步都从零开始找对齐，实践中能明显改善长句。它是后来 Transformer 解码器里“把上一层的输出和当前输入相加”的思想雏形之一。

3.4 从 Luong 到 Q/K/V：只差一次“换人”

把 general 打分拆开看：

score(st, hj) = st⊤ Wa hj
(3.3)

如果我们不再用 RNN 状态 st 当 query，而是让每个输入位置 xi 自己线性投影出一个 query；不再用 hj 直接当 key，而是让每个位置 xj 投影出一个 key；再把 Wa 吸收进这两个投影——就得到：

qi = xi WQ    kj = xj WK    score(i, j) = qi · kj
(3.4)

这一步的意义不只是“换个写法”。在 Luong 那里，query 仍然来自解码器的循环状态，一次只能有一个；换成人人自带 query 之后，一句话里所有位置可以同时发问，打分变成一个大矩阵乘法。剩下的问题只有一个：没有 RNN，顺序信息从哪来？

桥梁已经搭好

Bahdanau 贡献了“按相关性加权取回”的范式；Luong 把打分从 MLP 换成点积，让它可矩阵化；Transformer 要做的，是把 query 的来源从“解码器状态”换成“每个词自己”，然后一次性算完。

04
Stage 3 · 2017 · NeurIPS

Transformer：把“查”变成唯一的主干

既然解码器每一步都可以回头查，为什么还要用 RNN 来产生“每一步”？让每个词自己发问、自己挂标签、自己带内容，再用一次矩阵乘法把所有位置两两比较——循环就可以整个删掉。

Bahdanau 的注意力有一个隐含的前提：总得有人来提问。在 2015 年的模型里，提问者是解码器的循环状态 st−1；被问的是编码器的 hj。这两样东西都是 RNN 一步一步算出来的。所以注意力再有效，也只是挂在循环引擎上的一个附件。

Transformer 的问题很直接：如果提问者不再由循环产生，会怎样？答案是——句子里的每个位置都可以自己产生一个 query，去问所有位置；每个位置也都可以产生自己的 key 和 value，供别人检索。这样，一次矩阵乘法就能算完整张“谁该看谁”的表，不需要第 t 步等第 t−1 步。

4.1 从 Bahdanau 到 Q/K/V：四步改写

Q/K/V 不是凭空规定的三个新符号。把 Bahdanau 的公式摆在桌上，一步一步改，它们会自己长出来。

  • 把“解码器提问”改成“每个位置自己提问”

    Bahdanau 的 query 是 st−1，一个解码器状态，一次只有一个。自注意力让第 i 个位置用它自己的表示 xi 投影出 qi = xiWQ。于是“一对多”的 decoder→encoder 查询，变成了“多对多”的句内互查。

  • 把“被打分”和“被取走”拆成 K 和 V

    Bahdanau 里同一个 hj 干了两件事：当靶子被打分，当内容被加权取走。这两种需求会打架——为了好检索，希望向量像醒目的标签；为了好使用，又希望它保留完整信息。拆成 kj = xjWK 和 vj = xjWV，各自只对一件事负责。

  • 用点积代替小 MLP

    Bahdanau 的 va⊤tanh(Was+Uah) 要对每一对 (t,j) 单独前向。既然 query 和 key 已经分开，最自然的匹配就是内积：方向越一致，分数越高。所有 pair 的内积可以合并成 QK⊤ 一次矩阵乘法。

  • 不再需要循环来产生 Q/K/V

    把 BiRNN 换掉：直接对词向量矩阵 X 做三次线性投影，得到 Q、K、V。没有第 t 步依赖第 t−1 步，整句话的所有位置可以同时算。代价是顺序信息必须另外注入——这就是位置编码。

    • Bahdanau：   etj = va⊤ tanh( Wa st−1 + Ua hj )
    Transformer：   eij = ( xi WQ ) ( xj WK )⊤ / √dk
    (4.1)

    换一种写法，让三个角色更清楚：

    Q = X WQ    K = X WK    V = X WV
    Attention(Q, K, V) = softmax( Q K⊤ / √dk ) V
    (4.2)
    Q · Query

    “我想找什么”

    第 i 个位置发出的查询向量。它由 xi 投影而来，决定这一行要去匹配谁。

    K · Key

    “我是谁，方便被找到”

    第 j 个位置挂出的标签。它与 Q 做内积，决定“要不要看它”。

    V · Value

    “我有什么，可以被取走”

    第 j 个位置的实际内容。权重算好后，用它做加权求和。

    如果令 Q = K = V = X 会怎样？

    打分变成 xi⊤xj，对称且没有可学的投影；一个词也无法同时学会“怎样容易被找到”和“怎样作为内容被取走”。Q/K/V 的分离不是为了符号好看，而是为了让“检索”和“取回”各自拥有独立的参数。

    张量怎么来的形状含义
    X输入序列的词向量（+位置编码）n × dn 个位置，每个 d 维
    WQ, WK可学习投影d × dk把词向量投影到 query/key 空间
    WV可学习投影d × dv把词向量投影到 value 空间
    Q, KXWQ, XWKn × dk每个位置的查询 / 标签
    VXWVn × dv每个位置的内容
    QK⊤矩阵乘n × n所有位置对的相关性分数
    Asoftmax 按行n × n每个位置对全句的注意力权重
    输出AVn × dv每个位置取回的新表示

    论文的 base 设置：d = 512，h = 8，每个头 dk = dv = 64，所以每个头的 WQ 是 512×64。

    4.2 为什么必须除以 √dk

    公式里的 1/√dk 经常被当成“实现细节”跳过，但它是让 softmax 不饱和的关键。假设 query 和 key 的每一维都近似独立、均值 0、方差 1，那么它们的点积：

    q · k = ∑l=1dk ql kl   ⇒   E[q·k] = 0,   Var[q·k] = dk
    (4.3)

    也就是说，点积的标准差是 √dk。当 dk = 64 时，分数典型地在 ±8 附近摆动；送进 softmax 后，最大的那一项会迅速接近 1，其余接近 0，分布变得几乎 one-hot。此时 softmax 的 Jacobian 很小，梯度趋近于 0——模型“学不动”。除以 √dk 把方差拉回 1 附近，softmax 保持在有梯度的区间。

    一句话记住

    缩放的目的不只是防止数值溢出，更是防止 softmax 过早饱和、把梯度压没。没有它，维度越高，注意力越像硬选择，训练越难。

    4.3 多头：同时用几双眼睛看

    一次注意力只能学出一种“相关性”。但语言里的关系是多种多样的：主谓、指代、修饰、位置、标点……让一组权重同时承担所有关系，容易互相妥协。多头注意力的做法是：把 d 维分成 h 组，每组独立做一次注意力，再把结果拼起来。

    headi = Attention( Q WiQ, K WiK, V WiV )
    MultiHead(Q, K, V) = Concat(head1, …, headh) WO
    (4.4)

    原论文取 h = 8，每个头 dk = dv = 64。每个头有自己的 WiQ、WiK、WiV，最后用一个 WO ∈ ℝh·dv×d 把拼接结果投影回 d 维。总参数量与单头（同 d）相近，但表达的子空间更多。如果直接把多个头平均，不同子空间的信息会被抹平；拼接后再用 WO 投影，等于让模型自己学习如何组合这些视角。

    多头经常被浪漫化为“有的头看语法、有的头看指代”。确实能找到这样的例子，但更准确的说法是：多头提供了多个可学习的相似度度量。训练不会保证每个头都分工明确；很多头是冗余的，剪掉一部分性能也未必下降。它的价值在于“不必用一个度量同时满足所有关系”，而不是“每个头都必须可解释”。

    4.4 位置编码：把被注意力丢掉的东西补回来

    自注意力有一个容易被忽略的副作用：它天生对顺序不敏感。把输入序列打乱，输出也只是跟着打乱，模型本身无法区分“猫追老鼠”和“老鼠追猫”。这不是实现 bug，而是结构决定的。

    一句话证明：置换等变

    设 P 是置换矩阵。因为 (PX)W = P(XW)，所以 Q、K、V 都只是被同样的方式重排；分数矩阵变成 P(QK⊤)P⊤，softmax 按行作用后仍是 P A P⊤；最后乘 P V，得到 P(AV)。输出只是输入的置换，顺序信息从未进入计算。

    解决办法很直接：在把词向量送进第一层之前，给每个位置加一个唯一的“位置指纹”。原论文用一组不同频率的正弦、余弦函数：

    PE(pos, 2i)   = sin( pos / 100002i/d )
    PE(pos, 2i+1) = cos( pos / 100002i/d )
    (4.5)

    其中 pos 是位置（0, 1, 2, …），i 是维度编号（0 … d/2−1）。每一对 (2i, 2i+1) 是一组 sin/cos，拥有自己的频率。频率随维度呈几何级数下降：最左边变化最快，负责区分相邻位置；最右边变化最慢，负责区分句子的远段。

    位置编码与词嵌入逐元素相加，而不是拼接：xi ← xi + PE(i)。相加要求两者同为 d 维；模型可以在后续层里学会把“词义”和“位置”分别解码出来。注意它只在最底层加一次，而不是每层都加；之后各层通过注意力和 FFN 继续使用这份位置信息。

    为什么偏偏是 sin/cos？

    至少有三个原因。第一，每个位置都有唯一编码：不同频率的组合不会重复。第二，值域有界：sin/cos 永远在 [−1, 1]，不会随位置增大而爆炸。第三，也是最重要的，相对位移可以表示成固定旋转。对每一对 sin/cos，令 ωi = 10000−2i/d，则：

    [ sin(ωi(pos+k)) ; cos(ωi(pos+k)) ]
    = R(ωik) · [ sin(ωipos) ; cos(ωipos) ]
    (4.6)

    其中 R(θ) 是二维旋转矩阵。注意：旋转角只取决于位移 k，与绝对位置 pos 无关。这意味着“往右移 3 个位置”在每一对维度上都对应同一个固定旋转，模型很容易学会“相对距离”这类关系。这也是后来 RoPE（旋转位置编码）直接把这一性质搬到 query/key 上的原因。

    原论文的选择

    不用学，参数为零；可以外推到训练时没见过的长度（理论上）；相邻位置的关系由旋转保证。

    Learned / Relative / RoPE

    后来的演化

    可学习位置嵌入在 BERT/GPT 早期很常见；相对位置编码（Shaw et al., 2018）直接建模距离；RoPE 用旋转矩阵编码相对位置，成为 LLaMA 等模型的标配。

    4.5 前馈网络、残差与 LayerNorm：让深层堆叠成为可能

    注意力负责“位置之间通信”，但它本身是线性的加权求和（softmax 权重是非线性的，输出对 V 仍是线性组合）。要让模型具备足够的非线性表达能力，每个 Transformer 层在注意力之后还有一个逐位置的前馈网络（FFN）：

    FFN(x) = max(0, x W1 + b1) W2 + b2
    W1 ∈ ℝd×dff,   W2 ∈ ℝdff×d,   dff = 4d = 2048
    (4.7)

    4 倍不是理论推导，而是原论文的经验选择：给逐位置非线性变换足够的中间宽度，同时控制参数量。“逐位置”是关键：同一个两层 MLP 独立地作用在每一个 token 上，位置之间不交换信息。交换信息的工作全部交给注意力。这个分工可以概括为：Attention 做通信，FFN 做计算。FFN 的参数量通常比注意力还大（base 每层约 2.1M），它承担了大部分的“记忆容量”。

    每个子层（注意力和 FFN）外面都套一个残差连接和 LayerNorm：

    Post-LN（原论文）：   x ← LayerNorm( x + Sublayer(x) )
    Pre-LN（现代常用）：   x ← x + Sublayer( LayerNorm(x) )
    (4.8)

    残差提供一条“恒等高速路”：即使子层学得很差，信息也可以原样流过，梯度不必穿过层层非线性。LayerNorm 则在每个 token 的特征维度上做归一化：

    LN(x) = γ ⊙ ( x − μ ) / √( σ2 + ε ) + β
    (4.9)

    这里 μ、σ 是在单个 token 的 d 个特征上统计的，与 batch 无关。这一点很重要：NLP 的 batch 大小、序列长度都经常变化，BatchNorm 的统计量不稳定；LayerNorm 不依赖 batch，训练和推理行为一致。

    Post-LN 与 Pre-LN 的实践差异

    原论文用的是 Post-LN，需要精心设计 warmup 才能稳定训练。后来的大模型普遍改成 Pre-LN（或 RMSNorm），把归一化放在子层之前，残差路径上没有任何归一化，梯度更顺。你会在现代 LLM 的代码里看到 x = x + attn(norm(x)) 这种写法，就是 Pre-LN。

    此外还有 dropout：原论文在 sublayer 输出、词嵌入 + 位置编码、注意力权重上都用了 0.1 的 dropout。它和残差、LayerNorm 一起，构成了“能堆深”的三件套。

    4.6 整体架构：编码器–解码器，但每一层都是注意力

    把前面的零件组装起来，就得到 Transformer 的完整结构。它仍然沿用 seq2seq 的“编码器–解码器”骨架，但每个编码器层只有两个子层（自注意力 + FFN），每个解码器层有三个子层（掩码自注意力 + 交叉注意力 + FFN）。

    几个容易被忽略的结构细节：

    • 编码器和解码器各堆 N = 6 层，每层的输出维度保持 d = 512，所以可以反复叠加。编码器自注意力没有掩码，每个位置可以看到全句；解码器自注意力有因果掩码，只能看左边。
    • 交叉注意力是唯一连接两边的桥。编码器的输出只在这里被使用；解码器的每一层都会重新读一次 memory，而不是只读一次。
    • 解码器自注意力必须带因果掩码。训练时整句译文一次性喂进去，如果不掩码，第 3 个位置就能看到第 4 个词，属于作弊。
    • 输出层与词嵌入共享权重（weight tying）：d×词表 的矩阵既用于输入查表，也用于输出投影，减少参数量。

    4.7 掩码、训练与推理：并行从哪里来

    Transformer 的训练能并行，靠的正是因果掩码。把目标序列右移一位（前面加 <BOS>）后，整句一次性送进解码器；分数矩阵的右上三角在 softmax 之前被置为 −∞，softmax 后这些位置的权重就是 0。于是第 t 个位置只能看到 ≤ t 的位置，既不会偷看答案，又能一次性算出所有位置的预测。此外还有 padding mask：一个 batch 里长度不一的序列会用填充符补齐，这些位置在 softmax 前也被置为 −∞，避免模型把填充符当成内容。

    并行的准确说法

    Transformer 并不是“训练和推理都并行”。它并行的是序列位置：一层之内，所有位置同时计算。层与层之间仍然串行（N 层），推理时词与词之间也仍然串行。相比 RNN 的 O(n) 个时间步，Transformer 的串行深度是 O(N) 层，而 n 通常远大于 N——这才是 GPU 利用率提升的来源。

    代价也很明确：自注意力的分数矩阵是 n×n，时间和显存都随序列长度平方增长。这就是后来 FlashAttention、稀疏注意力、线性注意力、长上下文模型要解决的问题。

    “We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely.”

    — Vaswani et al., Attention Is All You Need, 2017

    这句话在当时更像一个大胆的主张：卷积在序列任务里已经很强，循环更是主流。但 Transformer 用结果证明了——只要注意力能提供足够的归纳偏置，循环和卷积都不是必需的。它把“序列建模”从“沿时间递推”改写成了“在一个全连接图上做加权聚合”。

    第四章留下的账

    解决了：训练时序列位置级并行、任意位置 O(1) 路径、可堆叠的通用模块、长距离依赖。
    没解决：O(n²) 的注意力成本、推理仍自回归、位置编码仍是外加的、超长上下文仍困难。这些正是 2018 年之后的研究主线。

    三次“换人”，而不是三次“换算法”

    Shift 1 · 2015

    从“记住”到“回看”

    不再要求编码器把所有信息压进一个向量；解码器每一步都可以重新检索源句。注意力首先是一个信息访问方式的改变。

    Shift 2 · 2015

    从“MLP”到“点积”

    打分从“每对跑一次小网络”变成“一次内积”，让注意力可以写成矩阵乘法。这是计算方式的改变。

    Shift 3 · 2017

    从“附件”到“主干”

    query 不再由循环产生，每个位置自己提问；循环被整个删除。这是架构的改变。

    什么没变

    注意力的核心始终是三件事：用某种相似度打分、softmax 归一化、按权重加权求和。Transformer 换掉了打分函数、换了 query 的来源、换了计算的组织方式，但没有换掉这个语义。这也是为什么 Bahdanau 的公式可以被“改写”成 Q/K/V，而不是被“推翻”。

    一条可复述的演进链

    定长瓶颈→每步重算→点积打分→去掉循环→位置编码补顺序
    阶段核心公式一句话
    RNNht = tanh(Whht−1 + Wxxt + b)顺序读，最后状态当摘要
    Bahdanauetj = va⊤tanh(Wast−1 + Uahj)；α = softmax(e)；ct = ∑αtjhj每步回头查，按权重取

    如果只记三句话

    1 · 问题是瓶颈：把整句话压进一个定长向量，长句必然丢信息。
    2 · Bahdanau 的答案是“每步重查”：当前状态与每个源位置打分 → softmax → 加权求和。
    3 · Transformer 的答案是“拆开 + 并行”：每个词自己发问（Q）、挂标签（K）、带内容（V），用点积和矩阵乘法一次算完。

    06
    Aftermath · 2018 – 至今

    之后发生了什么：一个模块，长出了一整个家族

    Transformer 的真正影响，不是它在 2017 年多拿了几个 BLEU，而是它提供了一个可以无限堆叠、可以跨模态复用的“通用计算块”。

    论文发表后，社区很快发现：这个块不必同时保留编码器和解码器。只取一半，就能得到两类完全不同的模型。

    Encoder-only

    BERT（2018）

    双向自注意力 + 掩码语言建模，擅长理解、分类、抽取、检索。它把“完形填空”变成了预训练任务。

    Decoder-only

    GPT（2018 →）

    因果自注意力 + 下一个词预测。结构简单、可扩展，最终成为 GPT-3、ChatGPT、LLaMA、DeepSeek 等 LLM 的主干。

    Encoder–Decoder

    T5（2019）

    保留完整的编码器–解码器，把所有任务统一成“文本到文本”，证明了架构的通用性。

    再往后，Transformer 越过 NLP：ViT（2020）把图像切成 patch 当 token；Whisper 处理音频；AlphaFold 2 用注意力处理蛋白质结构；扩散模型（DiT）用它生成图像。只要能把问题表示成“一组 token + 它们之间的关系”，这个块就能套上去。

    自测：你真的理解了吗？

    1. 为什么 Bahdanau 的 hj 是 2n 维，而 st 是 n 维？

    因为编码器是双向 RNN：每个位置把正向和反向的隐藏状态拼接起来，所以是 2n；解码器是单向 RNN，状态自然是 n。注意力打分时用 Ua 把 2n 维的 hj 投影到 n 维打分空间，才能和 Wast−1 逐元素相加。

    2. 为什么 Transformer 要除以 √dk？不除会怎样？

    点积的方差随 dk 线性增长，标准差是 √dk。不缩放时，维度越高分数越极端，softmax 越接近 one-hot，Jacobian 越小，梯度越容易消失。除以 √dk 把方差拉回 1 附近，让注意力在训练初期保持“软”。

    3. 位置编码为什么是“加”在词嵌入上，而不是拼在后面？

    因为模型维度 d 是固定的，拼接会改变维度，后续所有矩阵都要改。相加保持维度不变，且模型可以通过线性层学会把词义和位置分开。原论文也实验过可学习的位置嵌入，效果与正弦编码接近。

    4. 交叉注意力的 Q、K、V 分别来自哪里？

    Q 来自解码器当前层的输出（已经过掩码自注意力和 Add&Norm）；K 和 V 来自编码器的最终输出 memory。它复现的正是 Bahdanau 的模式：解码器用自己的状态去检索源句的所有位置。

    5. 因果掩码在训练和推理时分别起什么作用？

    训练时，整句目标序列一次性输入，掩码把每个位置的注意力限制在 ≤ 自身的位置，防止偷看未来，同时保留位置级并行。推理时本来就是一个词一个词生成，天然不会看到未来；掩码仍然保留，以保证训练/推理行为一致。

    6. 为什么说“Transformer 训练并行、推理不并行”？

    训练时所有目标位置的真实 token 都已知，掩码保证因果性，所以一次前向可以算所有位置的损失。推理时第 t 个词依赖第 t−1 个词的输出，必须逐词生成；KV cache 只是避免重复计算历史 K/V，并没有消除自回归的串行性。
